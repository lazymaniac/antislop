# antislop self-host milestone

The scoped milestone is complete: antislop compiled and completed a verified change to its own source. [Final acceptance](final-acceptance.json) and [root transfer verification](root-transfer.json) record the result. Completion of all design.md requirements is deferred.

The acceptance task is to add `--version` using `CARGO_PKG_VERSION` while preserving existing commands. Only `src/main.rs` may change. `scripts/selfhost.py --live` creates a private source copy and invokes the compiled antislop task driver with authenticated Codex CLI executor/verifier sessions. The runner executes Clippy, the full Rust test suite, a build, exact output checks and help regression checks. The final independent checker compares every source hash and resolves logical authors to distinct observed native provider sessions with durable outputs.

The daemon still enforces supervised approval scope hashes. The driver is explicitly authorized for the immutable task and a bounded number of repair rounds; it stops for uncertain effects or scope drift. This demonstrates scoped work, not unrestricted autonomous operation or full team-DAG integration.

`attempt-1.json` through `attempt-5.json` record actual experiments, not simulated results. Complete private runs and logs remain at the reported temporary paths. The fifth experiment produced the intended source change, passed the real runner and refreshed context/planning verification, then stopped because the main Execution verifier exited without a completed turn. Its cause was not captured by the old adapter. The blocked result is preserved; it is not final acceptance.

Recovery now preserves verified progress when every edit is checkpointed as Applied and actual pinned inputs equal the checkpoint. Reconcile itself performs no write or retry. Partial, missing or conflicting inputs still invalidate prior scope and restart Discovery. A separate scoped repair approval is required before continuing a blocked run. The `follow` command observes the original immutable run without creating another run or resetting its repair budget.

[Payload audit](payload-audit.md) records measured prompt duplication from that experiment. Reduction and improved safe CLI diagnostics are being verified before continuing the same run. Acceptance results will be recorded here only after final checks succeed.

The same run was continued with an upgraded coordinator. [Continuation audit](continuation-audit.md) verifies the actual new prompt/schema hashes and distinguishes coordinator builds.
